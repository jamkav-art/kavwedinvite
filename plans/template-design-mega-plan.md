# Template Design Mega-Plan — 8 World-Class Wedding Website Templates

## Overview

Completely replace all 8 existing wedding invite templates with **world-class, full-page website designs** for the invite page (`/invite/{id}`). Each template is a premium, scrollable wedding website with parallax effects, animated typography, gradient animations, and unique visual identities.

**Core Philosophy:** The invite page is the "money page" — this is what users see and what convinces them to pay. Each template must feel like a premium wedding website, not a digital card.

---

## Template 1: `celestial-navy` — Celestial Nights ✨

### Theme

Deep navy night sky with gold constellations, shooting stars, and celestial motifs. Perfect for evening ceremonies.

### Visual Identity

- **Background**: Deep navy blue (`#0A0E1A`) with subtle starfield particle animation (twinkling stars)
- **Primary**: Gold (`#C9A962`)
- **Secondary**: Soft lavender (`#E8E0F0`)
- **Accent**: Warm white (`#FFF8E7`)

### Key Features

- **Hero**: Full-viewport hero with animated constellation particles moving in parallax as user scrolls
- **Typography**: Gold animated gradient heading with `cinzel` font — subtle shimmer animation
- **Background**: Animated starfield with CSS-driven twinkling + floating gold sparkles
- **Sections**: Glassmorphism cards with navy/translucent backgrounds
- **Countdown**: Gold glowing countdown timer in hero
- **Gallery**: Masonry grid with gold frame borders, lightbox with starfield overlay
- **Timeline**: Vertical timeline with gold dotted connectors and constellation icons
- **RSVP Button**: Floating bottom button with gold gradient and star sparkle effect

### Animations

- Stars twinkle randomly (CSS keyframes with random delays)
- Shooting stars streak across hero (CSS animation, 15s interval)
- Scroll-triggered parallax on constellation layer
- Gold shimmer on heading text
- Cards fade+slide up on scroll reveal

## Technical Implementation Notes

### Performance Considerations

- Use CSS animations where possible (GPU-accelerated) over JS-driven
- Canvas-based particle systems for performance (not DOM-based)
- Lazy-load section components (dynamic imports)
- Intersection Observer for scroll-triggered animations
- Use `will-change` and `transform: translateZ(0)` for GPU layers
- Preload hero image + first section above fold

### CSS Strategy

- Each template gets a CSS module or CSS-in-JS stylesheet
- Animations defined as `@keyframes` in `globals.css`
- Template-specific classes use `[data-template="template-slug"]` selector
- CSS custom properties for template colors (already done)

### Animation Library

- **Framer Motion**: Page/section entrance transitions, spring animations
- **CSS @keyframes**: Continuous animations (particles, shimmer, float)
- **Intersection Observer**: Scroll-triggered reveals
- **Canvas API**: High-performance particle systems (stars, petals, bokeh)
- **GSAP** (optional): For complex timeline-based scroll animations

### Responsive Design

- Mobile-first approach
- Hero adapted for mobile (smaller text, simplified particles)
- Gallery: 1 column mobile, 2 tablet, 3+ desktop
- Touch-friendly interactions
- Reduced motion media query for accessibility
