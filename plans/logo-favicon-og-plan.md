## Execution Steps

### Step 1: Create `components/brand/WedInviterLogo.tsx`

**Location:** [`components/brand/WedInviterLogo.tsx`](components/brand/WedInviterLogo.tsx)

**What it does:**

- Pure SVG React component (no external images, no CSS imports)
- Renders a **heart-infinity symbol** — two interlocking teardrop loops that form both a heart shape and an infinity (∞) motif
- Uses SVG `<defs>` with `<linearGradient>` for the colorful gradient blend (Gold → Rose → Magenta → Champagne)
- Accepts a single `size` prop (number, defaults to 32)
- **Approved size tokens:** 20, 32, 40, 48, 80, 120, 200
- ViewBox is `0 0 100 100` for clean scaling
- Optionally renders "Wed✦Inviter" text below the symbol for combined logo-text usage
- **Two variants exposed:** `WedInviterLogo` (symbol only) and `WedInviterLogoWithText` (symbol + brand name)

**SVG Design Notes:**

- The heart-infinity symbol is drawn using two cubic bezier paths
- Left loop starts from bottom-center, curves up-left, loops around and crosses itself
- Right loop mirrors from bottom-center, curves up-right, loops around and crosses itself
- The overlapping center forms the heart's bottom point
- A `<defs>` gradient (`url(#logo-grad)`) applies: `#C9A962` → `#E8638C` → `#C0185F` → `#F7E7CE`
- A subtle drop-shadow `<filter>` adds depth

### Step 2: Generate all favicon/icon PNG files

**Location:** [`public/`](public/)

**What needs to be generated:**

1. [`public/favicon.svg`](public/favicon.svg) — Standalone SVG favicon
2. [`public/favicon.ico`](public/favicon.ico) — **Keep existing** (replace content if needed, keep filename)
3. [`public/favicon-96x96.png`](public/favicon-96x96.png) — 96×96 PNG
4. [`public/apple-icon.png`](public/apple-icon.png) — 180×180 Apple touch icon
5. [`public/web-app-manifest-192x192.png`](public/web-app-manifest-192x192.png) — 192×192
6. [`public/web-app-manifest-512x512.png`](public/web-app-manifest-512x512.png) — 512×512

**Generation approach:**

- The SVG for `favicon.svg` will be extracted from the `WedInviterLogo` component as a standalone file (same paths, same gradients)
- PNG files will be generated by an **npm script** using a headless approach:
  - Use `sharp` or `canvas` to render the SVG at required dimensions
  - OR use `next/og` ImageResponse to render the SVG at each size
  - OR generate a simple Node.js script using `sharp` to convert SVG → PNG at multiple sizes
- Since we can't easily render SVG-to-PNG in-browser, we'll use a **generation script** at `scripts/generate-icons.ts`

**Preferred approach — `scripts/generate-icons.ts`:**

- Uses a minimal Node.js script with `sharp` (already commonly available)
- Reads the SVG source, resizes to each required dimension
- Outputs to `public/` with correct filenames
- Run via `npx tsx scripts/generate-icons.ts`

**Fallback approach (if sharp fails):**

- Create each PNG manually using base64-encoded SVG data URIs rendered via a temporary Next.js API route
- Save responses as files

### Step 4: Update `app/layout.tsx` — Add icons + manifest to metadata

**Location:** [`app/layout.tsx`](app/layout.tsx)

**Changes:**

- Add `icons` property to the exported `metadata` object
- Order: SVG must be first in the array, then ICO, then PNGs
- Add `manifest` link to the metadata
- Add `other` metadata for `apple-mobile-web-app-capable`

**What to add (inside existing `metadata` object, after `robots`):**

```typescript
icons: {
  icon: [
    { url: '/favicon.svg', type: 'image/svg+xml' },    // SVG first (per rule)
    { url: '/favicon.ico', sizes: 'any' },               // ICO fallback
    { url: '/favicon-96x96.png', sizes: '96x96', type: 'image/png' },
  ],
  apple: [
    { url: '/apple-icon.png', sizes: '180x180', type: 'image/png' },
  ],
},
manifest: '/manifest.json',
other: {
  'apple-mobile-web-app-capable': 'yes',
},
```

**CRITICAL RULES enforced:**

- ❌ No `<link rel="icon">` tags added manually — using Next.js metadata API
- ❌ No `<head>` blocks added manually
- ✅ SVG is first in `icons.icon` array
- ✅ All existing metadata fields left untouched
